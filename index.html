Formulas

With d² = L² + T² and r = √(L² + T² − S²):

AF = L(LS − Tr) / d² BF = L(TS + Lr) / d² AE = T(TS + Lr) / d² DE = T(LS − Tr) / d² FH = BF(AF − t) / AF ∠BAF = atan(BF / AF)
