# Leaning Board Calculator

A board of length **L** and thickness **T** leans across span **S** between two verticals, resting on a support of thickness **t**. The page computes AF, BF, AA′ = CC′, DA′ = BC′ and BG, and draws the layout to scale.

Enter any two of L, S, H, h (support height) and θ (the tilt, ∠BAF); the rest are calculated. Each mode has its own validity rules, shown on the page.

Live page: https://caaat1.github.io/leaning-board-calculator/
