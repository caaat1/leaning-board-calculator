# Leaning Board Calculator

A board of length **L** and thickness **T** leans across span **S** between two verticals, resting on a support of thickness **t**. The page computes AF, BF, AE, DE, FH and the tilt angle ∠BAF, and draws the layout to scale.

Valid when T < S < L and 0 < t < AF.

Live page: https://caaat1.github.io/dog-house/
